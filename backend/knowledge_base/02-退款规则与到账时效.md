# 退款规则与到账时效

## 退款发起条件

退款申请需满足以下任一条件：七天无理由退货审核通过、质量问题退货质检通过、订单取消成功、缺货或超时未发货由平台主动取消。预售定金订单在尾款支付前取消可全额退定金，尾款支付后按普通订单规则处理。

## 退款金额计算

退款金额 = 实付金额 - 已使用优惠分摊金额 - 应由消费者承担的运费。

- 优惠券按商品金额比例分摊到每个商品，部分退货时只退回对应商品分摊后的实付金额；
- 满减、跨店优惠按同比例分摊，不因部分退货而重新计算门槛；
- 无理由退货扣除单程运费 12 元，质量问题退货运费由平台承担；
- 已使用的积分、余额原路退回账户，已过期的优惠券不予补发。

## 到账时效

平台在质检通过或取消确认后 1 个工作日内发起退款，银行与支付渠道处理时间如下：

| 支付方式 | 到账时效 |
| --- | --- |
| 微信支付 | 1-3 个工作日 |
| 支付宝 | 1-3 个工作日 |
| 储蓄卡 | 3-7 个工作日 |
| 信用卡 | 3-15 个工作日 |
| 花呗分期 | 3-7 个工作日，手续费按剩余期数退还 |

退款发起后可在订单详情页查看退款单号与进度。超过上述时效未到账，可联系在线客服核查支付渠道流水。

## 不支持退款的情形

- 已超过售后期且无质量问题的订单；
- 已激活的虚拟服务、已使用的会员权益；
- 质检发现商品被调包、缺少核心部件或存在人为损坏；
- 恶意批量下单、刷单被风控判定的订单，需人工复核后处理。

## 退款失败处理

若因原支付账户已注销、银行卡过期导致退款失败，平台会在 3 个工作日内通过站内信联系消费者，可改退至本人实名认证的支付宝或银行卡，需提供与原订单一致的实名信息。
